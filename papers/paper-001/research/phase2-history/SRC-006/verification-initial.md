- SRC-006-C004/C007/C008: Fact labels and correction judging are automated; the adapted comparator changes native granularity. External biographies are evaluator inputs, not detector or corrector inputs.

- Optional context, not a blocking omission: printed p. 5612 Ethical Considerations (PDF p. 10) explicitly warns that false positives/negatives remain and the method should not wholly replace human factual checking. Existing consistency and evaluation qualifications already prevent the summary from implying otherwise; add a tracked claim only if that explicit recommendation is reused.
